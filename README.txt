# Crear carpeta mediante terminal
- cd Documents 
- mkdir mi-carpeta (creo mi carpeta)
- puedes usar code . (para llamar a visual code studio)
- git init (inicio el repo local)
- touch README.txt (crear un archivo .txt, se encuentra con status "A" de added)
- git add README.txt (se comienzan a trackear los cambios, pasa al área de stagging)
- Ojo que si está en estado "M" (modified).
- git commit -m "comentario de los cambios"
- Tuve que crear un archivo practica en el mismo explorer de la carpeta ".ipynb".
